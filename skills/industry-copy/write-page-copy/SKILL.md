# Write page copy

## Preconditions

- The PRD (audience, tone, content inventory) and the intake answers as structured fields (never raw client text, D-267).

## Steps

1. Write for the audience in the PRD, in plain English, short sentences, one idea per paragraph.
2. Lead each page with the visitor's need and the business's answer to it.
3. Wrap every factual claim (years in business, prices, qualifications, awards, results, numbers) in `<Claim>`: the client confirms each before launch.
4. Use the client's own words for services and names. Never invent testimonials, reviews, prices or credentials.
5. Keep page titles under 60 characters and meta descriptions under 155.

## Decision guidance

- When a fact is missing, write around it or add a clearly marked placeholder and a question for the owner; do not guess.
- Regulated fields (legal, medical, financial): no promises of outcomes, no comparative superlatives.
- Match the tone in the brand section; when none is given, warm and professional.
