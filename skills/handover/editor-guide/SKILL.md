# Editor guide

## Preconditions

- The site is in production and the content structure is final.

## Steps

1. Explain, with the site's own file names, how to edit a page, add a blog post, change navigation and update settings.
2. Explain the schema errors the build shows and how to fix them.
3. List the accounts and services the site uses and who owns each after handover.
4. Keep it short, in plain words, with one example per task.

## Decision guidance

- Write for a non-technical editor. No internal pipeline details.
