# Proposals

Agents may not edit `docs/spec/`. When the spec is wrong, unclear, or silent, write a proposal here and wait for the owner. Copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-MM-DD-short-title.md`.

The owner decides each proposal. If accepted, the owner (not an agent) updates the spec files and adds an entry to `DECISIONS.md`, then sets the proposal's status to `accepted`, `rejected` or `superseded`.
