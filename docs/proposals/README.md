# Proposals

Agents may not edit `docs/spec/` on their own. When the spec is wrong, unclear, or silent, write a proposal here and wait for the owner. Copy [TEMPLATE.md](TEMPLATE.md) to `YYYY-MM-DD-short-title.md`.

The owner decides each proposal. If accepted, the owner updates the spec files and adds an entry to `DECISIONS.md`, or approves a specific proposal for an agent to apply: the agent then makes exactly the approved spec edits in a PR that contains only spec changes, and the owner adds the `DECISIONS.md` entry. Either way the proposal's status is then set to `accepted`, `rejected` or `superseded`.
